# CardCalendar V1.1 验收文档

文档版本：v1.1
验收对象：当前仓库 main 分支中的模块化单体实现

## 1. V1.1 范围

V1.1 在 MVP 核心闭环上补齐五类能力，全部为个人用户可操作、可查询、可追溯的能力：

1. 卡片字段与状态：支持 suspended 状态、币种、备注、进度周期起止日。
2. 免年费进度：支持直接录入当前累计值，系统自动计算 correction 流水并重算达标状态。
3. Dashboard 聚合与排序：新增仪表盘统计接口，卡片汇总支持剩余量、达标状态、名称排序。
4. 年费事件与提醒时间线：事件详情返回处理历史及关联提醒历史。
5. 账户删除可观测性：记录申请时间、清理完成时间、清理结果和重试次数，前端可查看。

## 2. 后端契约

### 2.1 卡片

GET/POST /api/v1/cards、GET/PATCH /api/v1/cards/{cardId} 返回和接收：

{
  "status": "active | suspended | archived",
  "currency": "CNY",
  "notes": "可选备注",
  "progressPeriodStart": "2026-08-01",
  "progressPeriodEnd": "2026-08-31"
}

- currency 为三位大写 ISO 4217 代码；后端统一转大写。
- status 仅允许 active、suspended、archived。
- progressPeriodEnd 不得早于 progressPeriodStart。
- 归档通过 POST /api/v1/cards/{cardId} 的 { "action": "archive" }；恢复使用 restore。

### 2.2 累计进度

POST /api/v1/cycles/{cycleId}/progress-entries 支持两种模式：

追加模式：{ "entryDate": "2026-08-06", "countDelta": 3, "amountDelta": 0, "note": "追加" }

累计模式：{ "mode": "cumulative", "entryDate": "2026-08-06", "currentCount": 12, "currentAmount": 0, "note": "直接录入" }

- 累计模式写 entryType 为 correction，增量为目标值与当前值的差。
- 进度达标时周期状态从 open 变为 qualified；修正为未达标时恢复 open。
- GET /api/v1/cycles/{cycleId}/progress-entries 返回当前值、剩余次数/金额和百分比。

### 2.3 Dashboard 与汇总排序

- GET /api/v1/dashboard?all=true 返回总卡数、使用中/停用/归档卡数、待处理事件数、达标卡数、未来事件数和 attention 卡片。
- GET /api/v1/cards/summary?all=true 支持 search、status、feeStatus、qualified、dateFrom、dateTo、sortBy、sortOrder。
- sortBy 支持 due_date、remaining_count、remaining_amount、qualified、name、created_at。

### 2.4 时间线

GET /api/v1/fee-events/{eventId}/history 返回：

{
  "data": {
    "history": [{ "id": "...", "action": "fee_event.status_changed", "occurredAt": "...", "metadata": {} }],
    "reminders": [{ "id": "...", "status": "completed", "completedAt": "...", "history": [] }]
  }
}

### 2.5 账户删除

- GET /api/v1/me/delete-request 返回当前删除状态、申请时间、清理完成时间、结果和重试次数。
- POST /api/v1/me/delete-request 校验 confirmation 为 DELETE，置为 deletion_requested 并撤销全部会话。
- 清理任务成功后匿名化邮箱和密码哈希，记录 deletion_cleanup_completed_at、deletion_cleanup_result 和 deletion_retry_count。
- 清理失败保留审计记录并递增重试次数，不清除用户数据。

## 3. 前端验收

- 卡片表单可维护状态、币种、备注和进度周期；列表金额按卡片币种展示。
- 卡片列表可按剩余次数、剩余金额、达标状态和名称排序。
- 卡片详情展示卡状态、备注、周期信息，并在年费事件下展示处理历史与关联提醒。
- 进度录入区可切换追加增量和设置累计值，累计值保存后刷新最新进度。
- 首页 Dashboard 展示总卡数、使用中卡数、待关注进度和未来年费。
- 设置页可查看删除状态、申请时间、清理完成时间、重试次数和清理结果，并可打开删除审计弹窗。
